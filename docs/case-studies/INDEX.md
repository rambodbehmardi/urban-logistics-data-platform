# Public Case-Study Map

This repository consolidates eighteen separate analytical workstreams into a
single synthetic vertical slice. Each case below is a public abstraction, not
a renamed copy of private code. No operational query, entity name, location,
policy value, or result was transferred.

| Public case study | Safe proof in this repository |
|---|---|
| Area-shift policy impact | Time-varying state and outcome marts |
| Dispatch acceptance monitoring | Attempt history and final-event selection |
| Dispatch-radius automation | Deterministic policy fixtures and replay safety |
| Revocation and restriction analysis | Versioned attempts and generic outcome cohorts |
| Delay-tier audit | Integer-valued rules and quality contracts |
| Weekly cancellation diagnostics | Terminal-event marts and stable denominators |
| Distance-policy validation | Synthetic event-time comparisons and limitations |
| Hold-and-batch switchback evaluation | State reconstruction at request time |
| Geospatial risk plausibility | Fictional grid bounds and anomaly flags |
| Regional dispatch root-cause analysis | Zone-level quality aggregates |
| Service-quality cohort analysis | Canonical outcomes and maturity-aware filtering |
| Courier recovery dashboard | Reproducible marts designed for a reporting layer |
| Fulfilment root-cause audit | Deduplication, lineage, and funnel-ready events |
| Fulfilment control surface | Metric contracts separated from raw events |
| Margin and fulfilment decision control | Ledger outcomes kept separate from event rates |
| Shift-mode audit | Effective-dated state and allocation-style reconciliation |
| Compensation-ledger analysis | Base, adjustment, reversal, and invariant checks |
| Utilisation and return analysis | Synthetic area-time panels and descriptive rates |

## Consolidation rationale

A reviewer can run one end-to-end system and inspect the shared engineering
foundations behind all eighteen themes: immutable raw evidence, deterministic
canonicalization, explicit grain, replay safety, event-time semantics,
reconciliation, observability, and honest analytical limits.
